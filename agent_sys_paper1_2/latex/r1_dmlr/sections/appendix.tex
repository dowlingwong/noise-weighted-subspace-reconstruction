\section{Protocol, artifact, and supplementary material}
\label{app:protocol}

This appendix documents the artifact release structure and the supplementary
material that accompanies the benchmark. Quantitative appendix content is
generated from the same locked analysis artifacts as the main text; no
number is copied manually into any appendix section.

\subsection{Manifests and schemas}

The artifact includes the full task, fault, model, and split manifests with
content hashes; the machine-readable event and manifest schemas; and the
deterministic stream validator. The trace schema version is pinned, and
forward-compatible readers are provided for older minor versions. The
randomization seed, run-order generation logic, balance checks, and
design-matrix estimability diagnostics are archived with the design-generation
script so that any schedule can be reproduced from its recorded seed and
input hash.

\subsection{Label book and adjudication}

The label book defines failure onset, terminal scientific invalidity,
recovery, and the five-level attribution hierarchy. The adjudication guide
specifies the blinded protocol, the separation of execution success from
scientific validity, the handling of ambiguous and insufficient-evidence
cases, and the verifier-version tracking. The adjudication agreement report
and per-trajectory adjudication records are released with the trace data.

\subsection{Deviations and exclusions}

The protocol deviations log records every pilot-to-confirmatory change with
its date, rationale, affected protocol section, and impact assessment.
Excluded and censored runs are listed with the eight-way censoring
classification (policy termination, budget exhaustion, infrastructure
failure, injector failure, observer failure, verifier failure, scientific
task failure, unknown), and the intention-to-treat analysis retains all
valid assignments.

\subsection{Data card and reproducibility}

The data card documents intended use, prohibited interpretations, licensing,
hosting, and the maintenance plan. The reproducibility checklist specifies
the exact commands to validate a sample trace, replay a deterministic run,
and regenerate one example endpoint and table from the raw traces.

\subsection{Artifact release inventory}

The benchmark artifact is versioned and released with:

\begin{itemize}
    \item \textbf{Schema and validator:} machine-readable event and manifest
          schemas with a deterministic stream validator.
    \item \textbf{Injectors:} six deterministic fault injectors with
          capability declarations, clean counterfactual generators, and
          replay tests.
    \item \textbf{Manifests:} immutable task, fault, model, split, and
          analysis manifests with content hashes.
    \item \textbf{Traces:} governed trajectory traces with provenance and
          licensing metadata; a de-identified public sample with
          access-controlled references for the full dataset.
    \item \textbf{Adjudication:} the adjudication protocol, label book,
          inter-adjudicator agreement report, and per-trajectory
          adjudication records.
    \item \textbf{Evaluation code:} computation of all primary and secondary
          endpoints, baselines, and paper-facing tables from raw traces.
    \item \textbf{Reproducibility:} a single documented command to validate
          the artifact, replay a sample trajectory, and regenerate one
          example endpoint and table.
\end{itemize}
