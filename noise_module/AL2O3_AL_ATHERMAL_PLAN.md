# Al2O3_Al_athermal reverse-engineering plan

Goal: reproduce the noise budget and pulse template in
`Al2O3_Al_athermal/{Er,Johnson,SQUID,TD,total}_noise.dat` and `signal.dat` as a
parametric `CompositeSpectrum` + pulse template inside this package, so the
reference dataset becomes a generatable/regression-testable model instead of
a static external file.

## 1. Dataset facts (tech details)

- Provenance: committed wholesale at `abce005` ("init before collab with
  paper repo"), never generated by this repo's code. `read_dat_1.ipynb`
  (same commit) documents the y-axis as the "professor's plot",
  `sqrt(S_phi) / microPhi0 / sqrt(Hz)` — i.e. all six `.dat` files are
  one-sided **amplitude spectral density (ASD)**, not PSD.
- Grid: 16384 points, log-spaced, 1 Hz to 3e7 Hz, identical across all six
  files.
- `total_noise` is the quadrature sum of the other four:
  `total = sqrt(Er^2 + Johnson^2 + SQUID^2 + TD^2)`, verified here to
  floating-point precision and matching the check already present in
  `read_dat_1.ipynb` (which used a much looser workflow-sanity threshold,
  `max_frac_dev <= 0.50`, `rms_frac_dev <= 0.20`).
- Notebook's bookkeeping split: `SQUID + TD` = "readout-limited",
  `Johnson + Er` = "device-limited".
- `signal.dat` is not a noise source — it is the detector pulse response in
  the frequency domain (flat at low f, steepening through ~f^0 -> f^-1 ->
  f^-2), consistent with a two-time-constant (rise/fall) pulse.

## 2. Fitted analytic model per component

Derived by log-log slope/corner fits against the tabulated values (matches
to 3-4 significant figures at every sampled point checked):

| File | Form | Fitted parameters |
|---|---|---|
| `Johnson_noise.dat` | `White` | ASD = 0.05505 uPhi0/sqrt(Hz) (flat, PSD = 3.031e-3) |
| `SQUID_noise.dat` | `White + PowerLaw(exponent=-1)` in PSD | white floor ASD = 0.300 (PSD 0.09); 1/f term amplitude 9.00 uPhi0^2*Hz; knee f_c ~ 100 Hz |
| `TD_noise.dat` | `Lorentzian`/`RollOff(order=2, kind="lowpass")` in PSD | low-f plateau ASD = 0.2445; corner f_c ~ 159 Hz; ASD ~ f^-1 above corner |
| `Er_noise.dat` | `PowerLaw` | ASD ~ 0.738 * f^-0.45 (PSD exponent ~ -0.9), no corner over the full band |
| `signal.dat` | 2-exponential pulse (Probst et al. 1995 form) | not yet fit; requires IFFT to time domain then fit `t0, An, At, tau_n, tau_in, tau_t` |

All four noise forms are already representable with existing
`spectral_models.py` classes (`White`, `PowerLaw`, `RollOff`/`Lorentzian`)
composed via `CompositeSpectrum` — no new component types are needed for the
noise side.

## 3. Homebrew vs. QETpy decision

- **Noise generation: homebrew**, on top of this repo's existing
  `spectral_models.py` / `NoiseGenerator.py` / `psd_resampling.py`.
  QETpy's `qetpy.sim.TESnoise` requires a `didv_result` (R0, Rload,
  inductance, beta, loop gain from a measured complex-impedance / dIdV fit)
  that does not exist for this dataset. Fabricating those bias-circuit
  parameters to back-fit 4 known ASD curves is a harder, more
  underdetermined inverse problem than fitting the curves directly, and the
  direct fit above already matches to a few significant figures.
- **Downstream filtering: reference QETpy's `OptimumFilter` formula**
  (`Psi(f) = template*(f) / PSD(f)`). This stage only needs a noise PSD and
  a pulse template, both of which exist here
  (`total_noise.dat` + `signal.dat`), so it is legitimate to either depend
  on `qetpy.OptimumFilter` or reimplement the formula directly once
  `signal.dat` has a fitted template (Phase 4 below).
- Cait's `pulse_template_2` and its noise-from-PSD synthesis
  (`get_cc_noise`/`noise_function`) are used only as **reference formulas**
  to reimplement inline, not as a `cait` runtime dependency (`cait` pulls in
  HDF5/CRESST-specific data handling not needed here).

## 4. Implementation plan

### Phase 1 — Parametric fit
- Add a fitting script (e.g. `noise_module/noise_module/fit_al2o3_athermal.py`
  or a notebook under `examples/`) that loads each `.dat` with `np.loadtxt`
  (the reference files are plaintext 2-column arrays, **not** the `.npy`
  `(2, N)` format `psd_resampling.load_psd_density` expects — that loader is
  reserved for the resampled artifact produced in Phase 2), converts
  ASD -> PSD by squaring, and runs `scipy.optimize.curve_fit` in log-PSD
  space against:
  - Johnson: constant.
  - SQUID: `S0 + A/f`.
  - TD: `S0 / (1 + (f/fc)**2)`.
  - Er: `S0 * (f/f_ref)**alpha`.
- Emit a `CompositeSpectrum` config (per the schema in `CONFIGURATION.md`)
  for each component and for the sum.
- Acceptance: reproduce `total_noise.dat` via quadrature sum with
  `max_frac_dev` and `rms_frac_dev` far below the notebook's original loose
  thresholds (target < 1%).

### Phase 2 — Build the noise PSD artifact (ASD -> usable optimal-filter PSD)
This is the step that turns the noise-budget files into something an FFT-based
consumer (`NoiseGenerator`, an optimal filter) can actually use. Two
sub-steps, in order:

1. **ASD -> PSD, sum in power, on the native log grid.**
   Independent noise sources add in power, not amplitude:
   ```python
   import numpy as np
   freq = np.loadtxt("Al2O3_Al_athermal/total_noise.dat")[:, 0]
   psd_total_native = sum(
       np.loadtxt(f"Al2O3_Al_athermal/{name}_noise.dat")[:, 1] ** 2
       for name in ("Er", "Johnson", "SQUID", "TD")
   )
   ```
   Equivalently, if working from the Phase 1 fit instead of the raw files,
   `CompositeSpectrum.evaluate(freq, df)` already returns this summed PSD
   directly (the component classes in `spectral_models.py` are defined in
   PSD/density space, so no manual square-and-sum is needed on that path).
   Either way, sanity-check against `total_noise.dat**2` before proceeding —
   this is the same quadrature-sum check as Phase 1's acceptance criterion,
   just kept as a gate here too since it's cheap and catches loader bugs.

2. **Resample from the native log grid onto a uniform rFFT grid.**
   Neither `NoiseGenerator` nor an FFT-based optimal filter can consume a
   log-spaced grid; both need `np.fft.rfftfreq(n_samples, 1/fs)` for the
   target sampling frequency `fs` and record length `n_samples`. Use
   `psd_resampling.py`:
   ```python
   from noise_module import psd_resampling as pr

   # Default since 0.3.1: in-band interpolation, i.e. a readout that is
   # band-limited before sampling (FLL SQUID of a few MHz + digitizer
   # decimation filter, or an analogue anti-alias filter as in ECHo). The
   # readout bandwidth can be stated explicitly with anti_alias_cutoff_hz.
   target_f, target_psd, meta = pr.inband_resample_psd_density(
       freq, psd_total_native,
       target_sampling_frequency=fs, target_samples=n_samples,
       allow_extrapolation=True,
   )

   # Alias folding is opt-in. With no bandwidth limit it folds ~60 copies of
   # the white SQUID+Johnson floor (30 MHz / 0.5 MHz) into the band: in-band
   # PSD x60, optimal-filter baseline sigma x5.7 on the default grid. Use it
   # only when the readout really has no bandwidth limit below 30 MHz, or
   # with anti_alias_cutoff_hz set to the real readout bandwidth:
   # target_f, target_psd, meta = pr.alias_fold_psd_density(
   #     ..., anti_alias_cutoff_hz=readout_bandwidth_hz)

   pr.save_psd_density("al2o3_athermal_total_psd.npy", target_f, target_psd)
   ```
   The saved `.npy` is the artifact consumed by Phase 3 (`NoiseGenerator`)
   and Phase 6 (optimal filter denominator).
- Cross-check the Phase 1 parametric route against a **non-parametric**
  baseline built directly from the raw `.dat` arrays via
  `psd_resampling.make_target_psd_density` / `synthetic_resample_psd_density`
  (no fitted functional form involved). Large disagreement between the two
  routes flags a bad fit before it propagates into Phase 3/6.

### Phase 3 — Wire into `NoiseGenerator`
- Build one `CompositeSpectrum([White(...), PowerLaw(...), RollOff(...),
  PowerLaw(...)])` from the Phase 1 fit and pass it as `noise_type` to
  `NoiseGenerator` directly (analytic path), or point `NoiseGenerator` at the
  Phase 2 `al2o3_athermal_total_psd.npy` artifact (empirical/resampled
  path), so it FFT-synthesizes a stationary Gaussian time series whose Welch
  PSD matches the reference budget on the working sample-rate grid.

### Phase 4 — Physical plausibility check (optional, not blocking)
- Sanity-check fitted magnitudes against textbook orders of magnitude from
  McCammon (Johnson noise `2 k_B T R`, TFN with the ballistic/diffusive
  suppression factor) for plausible mK-stage T/R values, and against the
  excess-noise model in arXiv:1907.11343 for the `Er` component's exponent.
  This is a plausibility check only — it does not feed back into the fitted
  parameters, since no dIdV/bias-circuit measurement exists to constrain it
  independently.

### Phase 5 — Pulse template (`signal.dat`)
- Add a physical pulse template to `templates.py` (currently only has
  artifact/glitch templates): the 2-exponential form
  `p(t) = An*(exp(-t/tau_n) - exp(-t/tau_in)) + At*(exp(-t/tau_t) -
  exp(-t/tau_n))`, matching Cait's `pulse_template_2`.
- Fit `t0, An, At, tau_n, tau_in, tau_t` in the **time domain** (IFFT
  `signal.dat` first) rather than fitting 3 poles directly in log-log
  frequency space, which is numerically unstable.

Implementation note: `signal.dat` stores magnitude only, so `t0` is not
observable. The data fit exactly with `tau_in = 5 us`, `tau_t = 1 ms`, and
`An = At`; this equality cancels `tau_n`. The implementation therefore
documents both unidentifiable parameters and uses a canonical geometric-mean
`tau_n`, rather than inventing phase information through a zero-phase IFFT.

### Phase 6 — End-to-end validation and the optimal filter
- Extend `validate_noise_modules.py` with a regression check: generate N
  synthetic noise realizations from the Phase 3 `CompositeSpectrum`/PSD
  artifact, Welch-PSD them, and compare against the original `.dat` ASDs
  with the same ratio/deviation diagnostic used in `read_dat_1.ipynb`.
- Add a `tests/` fixture that loads `Al2O3_Al_athermal/*.dat` directly as
  ground truth, so future changes to `spectral_models.py` are checked
  against this real reference dataset, not only synthetic configs.
- Build the noise-weighted optimal filter from the two artifacts now on a
  matching rFFT grid: the Phase 2 `target_psd` (denominator) and the Phase 5
  fitted pulse template resampled/evaluated on the same `target_f`
  (numerator):
  ```python
  template_fft = np.fft.rfft(pulse_template_2(t, *fitted_params), n=n_samples)
  optimal_filter = np.conj(template_fft) / target_psd   # Psi(f)
  ```
  (`Psi(f) = template*(f) / PSD(f)`, matching QETpy's `OptimumFilter`
  convention — see Section 3.) Confirm it reconstructs a known injected
  pulse amplitude on synthetic noise+signal traces generated by
  `NoiseGenerator` in Phase 3.

## 4a. Implementation status and record length

Phases 3--6 are implemented in `noise_module/al2o3_athermal.py`,
`noise_module/templates.py`, and their regression tests. Phase 4 remains a
non-blocking identifiability check: converting the fitted flux-noise
magnitudes into T/R constraints requires the missing flux-to-current transfer
and bias-circuit calibration, so no unconstrained physical parameters are fed
back into the empirical fit.

An analytic PSD removes interpolation error but does not remove a finite
record's low-frequency cutoff: an N-sample record has `df = fs/N`. Choose

`duration >= max(K * tau_slowest, 1 / f_min_of_interest)`

with K about 8--10 for pulse containment, then round `N = duration * fs` up
to a convenient FFT length. Here `tau_slowest = 1 ms`. At 1 MHz:

- 16384 samples contains 16.4 decay constants but has `df = 61 Hz`.
- 131072 samples (the default) contains 131 decay constants and has
  `df = 7.63 Hz`, resolving the 100 Hz SQUID knee well.
- 1048576 samples is appropriate when behavior down to about 1 Hz is
  scientifically important.
