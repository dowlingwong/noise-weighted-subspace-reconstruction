\section{Algorithms, manifests, and supplementary material}
\label{app:supplement}

\textit{[The appendix includes: complete algorithms for the value-of-
information and learned controller policies; full action-cost definitions
for every action subtype; randomization records and blocking structure;
propensity diagnostics for the verified-intervention dataset; per-arm data
and compute accounting with any unavoidable mismatches; the postcondition
rubric used by adjudicators; per-task-template, per-fault-family, and
per-training-seed breakdowns of all primary results; robustness checks
under alternative cost weights and non-inferiority margins; exclusions and
missingness by arm; the protocol deviations log; and the anonymous
reproducibility checklist. All quantitative appendices are generated
from the same locked analysis artifacts as the main text.]}

\textit{[The artifact release includes: controller and baseline policy code
with versioned configurations; the verified-intervention dataset with
propensity records and adjudication metadata; training-view construction
code with split and deduplication isolation checks; evaluation code for
all primary and secondary endpoints; and exact commands to reproduce the
primary controller comparison on the frozen evaluation set.]}
