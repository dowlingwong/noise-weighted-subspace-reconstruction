\section{Protocol, artifact, and supplementary material}
\label{app:protocol}

\textit{[The appendix will include the full task, fault, model, and split
manifests; the label-book and adjudication guide; randomization and
blocking records; pilot-to-confirmatory changes documented in the
protocol deviations log; excluded and censored runs with reasons;
adjudication agreement statistics; per-stratum results for all secondary
analyses; sensitivity analyses for interval-censoring, alternative onset
rules, and alternative recovery definitions; the data card with intended
use, licensing, hosting, and maintenance information; and the
reproducibility checklist. All quantitative appendices are generated from
the same locked analysis artifacts as the main text.]}

The benchmark artifact is versioned and released with:

\begin{itemize}
    \item \textbf{Schema and validator:} machine-readable event and manifest
          schemas with a deterministic stream validator.
    \item \textbf{Injectors:} six deterministic fault injectors with
          capability declarations, clean counterfactual generators, and
          replay tests.
    \item \textbf{Manifests:} immutable task, fault, model, split, and
          analysis manifests with content hashes.
    \item \textbf{Traces:} governed trajectory traces with provenance and
          licensing metadata; a de-identified public sample with
          access-controlled references for the full dataset.
    \item \textbf{Adjudication:} the adjudication protocol, label book,
          inter-adjudicator agreement report, and per-trajectory
          adjudication records.
    \item \textbf{Evaluation code:} computation of all primary and secondary
          endpoints, baselines, and paper-facing tables from raw traces.
    \item \textbf{Reproducibility:} a single documented command to validate
          the artifact, replay a sample trajectory, and regenerate one
          example endpoint and table.
\end{itemize}
