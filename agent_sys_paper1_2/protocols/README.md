# Protocol registry — Papers R1 and R2

Machine-readable, versioned protocol artifacts. Validated by
`scripts/validate_protocols.py`; deterministic schedules generated by
`scripts/design_generate.py`.

## Layout

| Path | Contents |
| --- | --- |
| `common/terminology.yaml` | Shared definitions of units, outcomes, event types, visibility classes, fault families, censoring, splits |
| `common/endpoint_registry.yaml` | All primary/secondary endpoints with analysis IDs and formulas |
| `common/claim_artifact_matrix.yaml` | H1-H4 claims bound to experimental unit, analysis ID, artifacts, manuscript destinations |
| `common/gap_report.md` | Phase 0 preflight: inventory, protected paths, compatibility map, gap report |
| `r1/pilot_protocol.yaml` | R1-P instrumentation and label pilot (mutable during pilot) |
| `r1/confirmatory_protocol.yaml` | R1-C confirmatory benchmark (frozen after pilot) |
| `r1/split_manifest.example.yaml` | Example split-manifest structure |
| `r1/analysis_plan.md` | R1 statistical analysis plan |
| `r1/deviations.md` | R1 protocol deviation log |
| `r2/controller_protocol.yaml` | R2-P offline feasibility + R2-C1 randomized controller study |
| `r2/intervention_dataset_protocol.yaml` | R2-C2 verified-intervention dataset construction |
| `r2/training_protocol.yaml` | R2-T matched post-training + R2-A factorial ablation |
| `r2/analysis_plan.md` | R2 statistical analysis plan |
| `r2/deviations.md` | R2 protocol deviation log |
| `designs/golden_outputs.yaml` | Golden hashes for deterministic design generation |

## Freeze rules

- Pilot protocols are mutable until pilot gates pass.
- Confirmatory protocols are frozen before confirmatory collection; any later
  change requires a dated deviation record in `deviations.md`.
- R2 must consume the frozen R1 contract without changing R1's held-out groups
  or outcome definitions.
